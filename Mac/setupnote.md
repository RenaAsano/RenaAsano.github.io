# Mac 手動移行メモ

卒業を機に Mac Book Air を大学に返却したので、学割と新生活セールを利用して Mac Book Air を買いました。
以下は (学生の Mac 貸与は止めるらしいですが) 今後借りた人や次回も Mac に乗り換える私向けのメモです。

1. 新しい Mac を買う  
   学割が効くうちに買いましょう。
   2-4 月にはセールとして 2 万円分ほど Apple Gift Card がついてきます。
   あまり直前だと返却に間に合わないので修論発表が終わったらすぐ買いましょう。
2. 古い Mac から情報を消す  
   SSH 鍵やメールアドレスを抹消しましょう。
   見落としやすいのが `git config` で設定しているメールアドレス。
   個人利用は禁止されているので抵触しそうなものも消しましょう。
   個人利用にあたりそうなファイルはあらかじめ隔離しておくと楽です。
3. 設定ファイルを取り出しておく  
   私は GitHub に `dotfiles` をプライベートリポジトリとして作りました。
   入れたファイルは主に下記の通り。
   - .zshrc
   - funcs.sh (自作コマンド定義ファイル)
   - .Brewfile
   - .gitconfig
   - .gitmessage.txt
   - VSCode の setting.json
4. 新しい Mac で dotfiles をクローン  
   ホーム直下にシンボリックリンクを貼るスクリプトを同梱した方がいいです。
5. 新しい Mac で Homebrew をインストール
6. Homebrew で万物をインストール  
   この時に VSCode の拡張機能もインストールされます。
   `brew bundle` で MacTeX だけ失敗したため、それは個別に入れました。
7. VSCode の確認  
   日本語化だけは手動で再インストールして再起動しないと反映されません。
